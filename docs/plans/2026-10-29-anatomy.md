# Anatomy scene integration

Approved direction: the user requested full implementation on 2026-10-29 following the proposed scene-object design. Execute in the main agent; no commits or delegation.

## Architecture and invariants
- A parametric model entity carries optional AnatomyState. Its generated meshes are Babylon meshes under the ordinary object root.
- src/anatomy/parameters.ts defines the typed v5 parameter contract; catalogue data defines all 83 controls plus the surface selector.
- src/anatomy/geometry.ts and reference.json contain the original numerical kernels and authored CC0 mesh. They load only in a module worker.
- src/anatomy/material.ts ports the original fragment shading, with body-local coordinates and world-space camera conversion. Scene transforms remain independent from anatomical proportions.
- src/anatomy/body.ts owns worker lifecycle, stale result rejection, materials, inspection, undo, comparison, camera framing and project restoration. No DOM.
- src/ui/panels/anatomy.ts renders existing DOM components, search, regional navigation, profiles, composition, mixing, layers, materials, local studio lighting and actions.
- The editor registers the object using existing entity/history methods. project.ts stores optional state and restores it through the lazy feature.
